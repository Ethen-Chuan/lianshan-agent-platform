# 业务助手 · 独立模型连接

2026 年 11 月 8 日。本版是单人本机演示，不是生产密钥管理平台。

## 操作位置

进入“自动化助手”，每个助手的卡片都有“独立模型”入口；也可从“配置策略”切换到“模型连接”。售后接待助手、工单填写助手、对话质检助手各自拥有独立的服务商、模型 ID、密钥、连接修订和测试状态。不会默认共用或继承其他助手的密钥。

## 两种打开方式

**单文件 HTML**：只预览配置流程。可以保存服务商与模型 ID 草稿；API Key 输入和真实测试被禁用，不向任何模型服务发送请求。单文件没有密钥服务，不能把“保存草稿”称为已接通。

**本机服务**：在本源码目录运行 `node server.js`，从 `http://127.0.0.1:4328/#agents` 打开。需要支持全局 fetch 的 Node.js，开发验证使用 Node 25。未改端口时只接受上述本机主机名，不使用 localhost 或局域网地址。设置 PORT 可修改端口。

在“模型连接”中依次选择服务商、填写账号可访问的文本对话模型 ID、输入专属 API Key，再点击“保存连接”。保存不会调用外部模型。随后核对固定目的地与测试内容，勾选本次授权，点击“测试连接”。

百炼限北京地域 API Key；未实现其新业务空间专属域名和其他地域配置。官方兼容接口文档核对时仍支持上表旧域名。当前不接受任意代理、Azure 地址或自建模型地址；没有为了通用性放开可访问本机内网的转发接口。

模型 ID 手动填写，不预置“最新模型”列表。连接测试限定文本对话，不承诺兼容服务商的全部图像、音频、推理或其他专用模型。OpenAI 使用 max_completion_tokens，其他三种接口使用 max_tokens；上限 256，不传温度，不自动降级或换模型。

## 密钥如何处理

- 输入框使用密码类型；成功或失败的提交后清空，关闭窗口时也清空。
- 浏览器只保存服务商和模型 ID，不保存 API Key、密钥尾号或测试通过状态。
- 密钥只留在 Node 服务进程内存，不写文件、数据库、日志、Trace、导出、URL 或 API 响应。重启服务后必须重新输入。
- 保留同一服务商时可留空沿用该助手密钥；替换密钥或模型将作废旧测试。更换服务商必须输入新密钥。
- “移除连接”删除当前助手的内存密钥和浏览器配置，不影响其他助手，也不能替代到服务商控制台撤销密钥。
- 本机请求检查 Host、Origin、会话校验值和 JSON 类型；浏览器不直接连接服务商，服务端不跟随重定向。
- 当前没有企业身份、角色隔离、硬件密钥保护、持久凭证托管或双人审批。拥有本机访问权限的人仍处于信任边界内，不得公网部署。

## 什么情况下才会调用与计费

只有明确勾选授权并点击测试才发送一条固定英文问候，要求回复 OK。不发送客户对话、工单、知识库、用户编辑提示词或其他助手资料；也不解析或执行模型工具调用。

每次授权仅用于一次请求。刷新、修改模型、填写新密钥以及测试完成后都需重新确认。最多同时测试两个助手，每个助手只能有一个测试。超时 30 秒，不重试、不切换模型；超时或移除连接并不保证上游不计费。

成功仅表示收到可用文本响应，不等于客服正确率、工具能力或任务完成。401/403、额度或限流、模型不兼容、空响应、超时分别显示说明，错误不回显上游原文。失败不会被本地预设回复伪装成成功。

## 未接通的部分

本版新增的是独立配置与连接测试，未将真实模型用于客服自动回复、工单字段抽取、质检判断或 项目助手 调度。原“试运行”仍是本地预设测试，界面保留说明。

下一步若要让真实模型处理业务，需要另行实现：带用途授权的模型调用、必要上下文裁剪、业务工具白名单、实际运行模型版本 Trace、人工审核、超时处理和独立业务验收。连接测试通过不能替代这一步。
