# 客户模型对话 · 2026-11-11

## 本轮打通什么

「客户体验」从默认播放预设回答，改为自由输入问题、调用所选服务商的文本模型，并带上当前会话继续追问。旧场景保留在「流程回归」，两类历史分开显示；调用失败不会换成旧规则回复。

只打通售后项目接待助手的客户体验入口。群聊、Orbit、客服工作台自动回复、填单与质检仍使用原本地逻辑，没有宣称整个平台已经接入模型。

## 使用步骤

1. 用 `npm start` 启动本机服务；默认端口为 4333。`npm run preview` 启动的是静态版，不提供模型接口。
2. 进入售后项目的「客户体验 → 模型对话」，点击「配置模型」。
3. 选择 OpenAI、DeepSeek、通义千问百炼或 Anthropic，填写自己账号可访问的文本模型 ID 和密钥。服务商地址固定，不接受任意代理地址；百炼使用中国内地北京区域。
4. 保存配置后关闭弹窗，点击「新对话」。独立的连接测试是可选步骤，不会提交客户问题。
5. 勾选本次会话的数据范围与费用确认，再输入脱敏问题，例如「我的 A1 在哪里查看软件版本？」。可以改写问法、追问或要求人工处理；未提供型号时应先追问。
6. 回复中查看参考知识。模型回答后由体验者明确确认解决，或携带记录转到本地客服收件箱；不会提交真实工单、退款或接通真实客户渠道。

密钥只保存在服务器进程内存中，不写到浏览器存储、日志或静态构建，重启服务后需重新配置。用户应只在密码输入框填写密钥，不发到聊天、知识库或源码中。

## 数据流与限制

- 浏览器将当前会话中的客户与助手文字，以及匹配的已发布知识提交给同源本机服务；服务端校验后代理模型请求。
- 内部备注、工单、其他客户会话、知识负责人字段与项目本体不进入此请求。配置框单独的连接测试仍只发送固定英文问候。
- 数据发送授权只在内存中保存，按会话与连接版本隔离；刷新页面、新建会话、移除或更换连接后需要重新确认。不自动勾选，不自动重试。
- 每次客户输入最多 800 字；每会话最多 15 轮，提交上下文还有总长度限制，不静默截断。长对话需新建测试，原历史仍保留。
- 知识按客户明确提供的单一产品编码与中文词面重叠检索，最多 6 条、每条最多 4,000 字。已发布的新条目可以参与匹配，未审核或停用条目排除。
- 这是简单词面检索，不是向量 RAG、重排或完整语义检索。多个型号并存或没有明确型号时不自动选择；知识文档版本不当作客户的软件版本。
- 服务端默认 30 秒超时，客户端提供停止与手动重试；停止只发出取消信号，无法保证服务商不再计费。失败重试沿用原用户消息，不重复追加。
- 模型只返回回复、状态和本次知识 ID；不接受工具调用。结构、引用或基础风险检查失败时显示错误，不展示未经核对的原文。
- 新会话、转人工、知识下线、连接或接待策略改变后，过期返回不会继续写成有效回复。刷新页面不续发未完成请求。
- 交接后的消息走原本地客服会话，模型停止回复；客户确认解决仍是演练记录，不是线上效果数据。

## 安全边界

本机服务固定监听 `127.0.0.1`，API 检查 Host、Origin、跨站请求和会话令牌；密钥与聊天请求不由浏览器直接发往服务商。公开静态构建禁用这些接口，不能在 GitHub Pages 中填写密钥来调用模型。

这仍是单人本地测试环境。已发布知识由当前浏览器提供，服务端没有企业知识权限库、用户身份认证或租户隔离；本地运行策略也不是服务端生产权限。若浏览器状态或同机环境被篡改，不能依靠“已发布”标签充当可信授权。

敏感信息正则、固定系统提示词和引用 ID 检查只是基础防线，不能保证完全拦住个人信息、提示词注入或不实内容，也不能验证知识是否真正支持每句话。使用前需人工确认知识、适用版本、模型输出和服务商数据政策；只输入合成或已脱敏内容。

上线前还需服务端身份与权限、可信知识检索、模型效果评测、限流与费用控制、审计、工具授权、幂等和失败恢复。本轮不提供自动业务操作，不把模型返回文字当作业务系统回执。

## 验证与交付范围

- 新增的服务端与交互测试使用注入的模拟服务商响应，没有使用真实账户密钥、没有产生付费调用。
- 覆盖四类接口请求结构、多轮上下文、已发布知识匹配、授权与版本校验、跨站拒绝、敏感信息拦截、错误与超时、取消、手动重试、知识下线、项目切换、人工交接、15 轮限制和页面重开。
- 使用 `npm run check` 重新构建并运行全量回归；后端文件不会进入 `site/` 或 `docs/`。本机接口另做不含密钥的连通性检查。
- 本轮浏览器控制连接不可用，未完成交互实机与视觉验收。未配置真实模型，所以实际服务商连通性、模型回答质量和账号额度仍待用户配置后验收。
- 原件保存在工作区的 `work/customer-model/before/`；本轮未提交、推送或部署公共站点。

本次会话已启动 `4341` 端口的本机服务，并验证接口、静态资源与未授权请求拒绝；目前没有配置任何模型连接。原 `4340` 保留为静态预览，其浏览器历史不会自动迁移到新端口。最终合并画布与按钮改进后，全量 274 项自动测试通过，模型专项为 30 项；实际服务商调用仍待配置密钥后验证。
