# 关系图拖动与可读性升级

日期：2026-11-11。版本：v0.2.0。

## 2026-11-12：按参考录屏改为轻量星图

本节内容纳入 2026-11-12 的源码与静态演示发布范围。开发阶段与验收限制保留如下；发布状态以 [发布记录](RELEASE.md) 所列核验方式为准。

- 保留连山原有外壳，星图单独使用墨蓝画布、细曲线、小圆点／菱形与开放文字；分类改为细标题，不再用大卡片和大分组框包裹。
- 中心点 28px，外围点 16px；节点点击区仍包含完整名称与编号，不要求精准点中小圆点。名称按内容换行，中心摘要单独留出空间。
- 连线连接真实小节点，并避让名称和分类标题；同一对对象的平行、反向关系分别保留路径与标签，不把它们合并。
- 工具栏可选单个节点或关联分支。后者只同时移动被拖节点和直接相连的可见节点，不递归拖走整张图。一起移动的节点具有同步反馈，原有相对位置保持不变。
- 松手时分支整体避让其他节点；上边和左边有限位，下边和右边允许画布扩展。Esc、指针取消、失去捕获、失焦、隐藏页面、重绘及切换拖动模式都会恢复此次拖动前所有成员的位置。
- 方向键按当前拖动模式微调，Shift 加大步长。手动位置和模式只在当前视图状态内保存，不写入模型定义或持久化业务数据，项目之间隔离。
- 入场和中心切换保留 380ms 过渡，选中强调 200ms；亮点沿同一条插值曲线短暂经过，不循环，也不在原因假设上播放。拖动或关闭动效立即清理临时状态；减少动态效果和密集图不播放关系亮点。
- 拖动提示固定在图面内，不必滚到页尾查看取消方式。未改变端点且仍不穿过当前节点或标题的曲线可以复用；新的遮挡出现时重新寻路，减少拖动中的重复计算。
- 保留分类、高亮、关系清单、显式设为中心、历史返回及卡片图；没有新增模型请求、工具执行或授权变动。
- 参考视频先在本地拆帧扫描并人工检查，原件未修改，素材不加入仓库。自动规则未发现明确敏感项，视觉素材仍存在人工检查边界。
- 交互、几何和回归测试不替代实机验收；浏览器原生控制桥不可用，未取得新版渲染截图，当前视觉验收状态见根目录 `design-qa.md`。

本轮本地检查：458 项测试通过；74 个入口与样式／脚本资源经 HTTP 比对一致，入口比对包含服务器既有的本地连接策略替换。当前没有配置模型连接，测试和图谱交互没有调用付费模型。文件复扫自动规则未发现明确敏感项。

## 后续：先分类，再阅读关系

本轮只更新本地界面与构建产物，不表示已推送 GitHub 或更新公开站点。

- 星图按现有语义角色分组：同义表达、适用范围、待核实信息、原因假设、处理规则、业务动作与人工确认；分类框不计入定义数量，不新增本体对象。
- “黑屏／屏幕不亮”归入同义表达，与显示终端的适用范围分开。原因假设保持“待验证”与虚线，不能归为已核实依据。
- 只有组内各条目都通过同名、同向关系连接同一中心，且没有额外关系时，才将重复关系标签归到组标题；概览不再重复显示“同义表达”。底层每条关系、方向和编号不变，关系清单仍可逐条查看。
- 点击组标题高亮这一组，点击条目显示精确关系，二者都不改变中心和排布。不同关系名称、反向关系和成员间的额外联系仍分别标注，不合并成虚构关系。
- 中心连线按外围节点位置分配不同接口，尽量减少交叉。自由拖动时更新分组范围；如果外框会遮住其他定义，暂时隐藏外框并恢复条目分类与关系标签，取消拖动后恢复。
- 分组、节点与连线协调入场；换中心和展开路径用 380ms 平滑过渡，选中只做 200ms 局部强调。超过 18 个节点或 24 条关系时不做连线路径变形，降级为淡入。
- 新增“动效”开关和“重播”，只保存于当前视图状态。拖动、缩放、键盘移动、失焦、隐藏页面或重绘时清理动画，后台页面恢复后不自动重播；遵循系统减少动态效果与高对比偏好。
- 新增确定性动效和分类检查，覆盖中断、减少动态效果、后台恢复、精确曲线恢复、分组与单项选择、长标题、重复关系与方向差异、自由拖动和业务数据不变。浏览器控制连接不可用，尚未完成实机视觉验收；这些检查不替代截图与浏览器端到端测试。

## 后续：星状图的对象聚焦

这次调整针对星状图，不改模型调用、助手创建或业务执行。源码和静态产物已更新，本节本身不表示已推送或发布。

- 星状图核对一个对象与信息、规则、动作之间的关联；卡片图仍用于分区逐项查看同一份定义。
- 深苔绿中心与紧凑的外围节点分出主次；识别与依据、规则与处理分别自动排布，原因假设标为待验证。自由拖动不会改变节点类型或关系。
- 点击节点仅高亮，不换中心、不重置画布滚动。通过“设为中心”深入，通过“返回上个中心”返回；两次查看同一中心时保留本会话的手动位置。
- 图下提供实际关联路径，例如“屏幕无显示 — 触发 → 先核实保修 — 执行 → 核实保修”。点击后展开原有节点和连线，再点收起，不补造“对象直接执行动作”的捷径。
- 路径查找沿原有方向，最多检查四层，遇到首个动作或人工确认即停止；每个目标展示一条最短关联路径，不穷举所有可达路径。叫法、范围和原因假设不参与这项动作路径查找。
- 路径是已登记定义，不是运行轨迹，也不代表规则已进入某位助手。是否被采用仍以图下实际引用和已验收快照为准。
- 节点按各自标题留出高度，外围不再为别处的长标题一起变大。初次进入保持可读比例并定位中心，完整全图可用“适应画布”查看。
- 不在每次选中节点时闪动整张图。保留视图切换淡入、按下／聚焦／拖动反馈，适配减少动效和高对比偏好。
- 本地直达星状视图可使用 `?project=AFTERSALES&design=definitions&map=star#orbit`；不改变未带此参数的默认视图。

新增检查覆盖语义分组、直接与间接关系、路径方向、循环和失效路径、中心切换与返回、滚动和键盘焦点、长标题、空图、项目隔离和数据不变。浏览器控制连接仍不可用，未取得新版实机截图，不把自动化检查替代视觉验收。无付费模型调用，无新增对外数据发送。

## 本轮变更

- 覆盖业务设计预览中的星状图／卡片图，以及业务定义目录中的两种图，而不是仅更新一个入口。
- 节点整个区域可拖动，空白画布可平移；鼠标与单指触控使用相同坐标换算。拖动超过阈值后不再触发误点击。
- 拖动时同步更新节点、方向连线与关系标签；松手后避免节点重叠。Escape、指针取消、失焦、页面重绘会回滚未完成的拖动。
- 提供缩放比例、放大／缩小、适应画布和恢复排布。键盘方向键可微调，Shift 加大步长。
- 同一会话内星状／卡片布局和不同中心对象分别保留位置；项目之间隔离。刷新浏览器后恢复自动排布，不存储业务资料到新的持久化入口。
- 标题完整换行，节点高度按最长标题预留；子元素不参与弹性压缩。字段和说明显示明确摘要，悬停提示与节点详情可查看全文。
- 纸白节点、深苔绿选中面、清晰编号与分段工具栏取代胶囊式排布；补齐拖动、按下、聚焦和视图切换反馈。
- 减少动态效果与高对比偏好有专门适配。拖动不依赖动画，也不每帧重绘整个应用。

## 保持不变

两种图只改变同一份定义的表现方式。节点位置不写回业务本体，不修改修订号、已验收快照、模型授权或助手启用状态；关联箭头和节点序号不表示执行顺序。
