# Orbit 与业务定义整合

日期：2026-11-11。本次仅本地修改与构建，没有推送或部署。

## 使用方式

1. 从左侧「Orbit / 业务设计」进入，在流程设计里描述业务；文字与语音继续使用同一个输入框。
2. 需要复用字段或规则时，点击「选择定义」。在同一个工作台查看关系图或定义目录，并引用已有定义。
3. 新增、编辑、建立关系都使用原项目的业务定义，不再切换到另一套本体编辑画布。同名新增会被阻止。
4. 返回流程后，选定定义显示为可点击标签。模型仅在用户确认发送范围与费用后读取这些定义；生成修改还需核对并采用。
5. 已采用的引用有独立快照。定义修改会出现在流程引用提示、定义详情和变更影响里，不自动改写流程、配置草案或已验收版本。

## 保留的区别

- 流程图表示处理步骤、条件与交接。
- 定义关系图表示对象、规则、字段和动作之间的业务关系，不是另一张待执行工作流。
- 两者共享定义来源，但不自动将每个流程步骤注册成一条共享定义。
- 流程生成参考与已验收配置约束仍分别标明；此轮没有增加任意工作流执行、真实系统调用或自动发布能力。
