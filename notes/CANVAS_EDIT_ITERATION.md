# 画布编辑与测试入口 · 2026-11-11

## 修复内容

- 原来进入“画布指令”后，点击节点只改选择状态，没有切回节点编辑页；现在点击节点和明确的“编辑”按钮都会打开编辑表单。
- 节点卡片常显“编辑”和删除图标，上方选中工具栏提供“编辑节点 / 删除节点”；按钮不触发节点拖动。
- 连线点击范围加宽，选中后高亮并显示“编辑连线 / 删除连线”。编辑表单可修改起点、终点和关系条件，不必先删除再重连。
- 修改连线时保留原标识与条件分支出口；拒绝自连、重复关系、循环、无效起终点、占满的出口与相同分支条件。
- 删除节点前显示关联连线数量；确认后只删除当前节点及关联边，不自动连接两侧步骤。删除连线保留节点，均支持撤销和重做。
- 删除确认绑定当前项目与画布快照，变更过期后不能继续删除。已发布助手与其他项目不受影响。
- 画布内支持 Delete / Backspace 删除、F2 编辑、Ctrl / Command + Z 撤销、Shift + Ctrl / Command + Z 重做；输入框和弹窗不拦截文字编辑快捷键。
- 节点内容未完成时允许保存草稿；生成助手时仍按原有完整性检查，不放宽发布或验收。
- 客户体验“流程回归”的异常场景直接展示为两个带“开始测试”的按钮，不再使用默认折叠的文字链接。原场景逻辑不变。

## 验证

`tests/orbit-edit.test.js` 覆盖编辑入口、保存、节点级联删除、连线改接、撤销 / 重做、过期确认、跨项目保护、快捷键、预览互斥、转义和异常测试入口。全量检查使用 `npm run check`，重新生成静态站点。

本轮全量 274 项自动测试通过，其中画布与入口专项 13 项、模型链路专项 30 项；运行环境为本机 Node.js 25.9.0，未声明在 Node.js 22 上实测。本机检查确认 4340 已提供新版脚本，4341 提供模型配置接口且拒绝未授权聊天请求，后端文件不对外提供。没有使用真实模型密钥。

本轮浏览器控制连接不可用，因此未声明实机视觉验收通过；需要在本机页面检查节点按钮、窄屏工具栏和鼠标拖动感受。旧 `4340` 静态预览可展示更新后的界面，模型接口另在 `4341` 本机服务提供；不同端口的浏览器记录不自动互通，不迁移用户历史。
