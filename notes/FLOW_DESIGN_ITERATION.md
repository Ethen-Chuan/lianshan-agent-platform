# 可视化业务设计与工作区交互升级

日期：2026-11-10。本轮修改本地脱敏版并构建静态预览；未提交、推送或更新线上站点。

## 业务流程画布

Orbit「业务设计」默认展示流程画布，保留「文字描述」入口。两个入口都进入同一套助手配置、案例验收和人工纳入团队流程。

- 支持业务入口、收集信息、条件分支、处理动作、人工确认、交付结果六类节点；可从工具箱拖入，也可点击添加。
- 整张卡片均可自由拖动，支持方向键微调、可选网格吸附、缩放、撤销和重做。手动移动允许有意重叠，不再强制跳开；自动整理可恢复清晰排布。
- 从箭头出口拉到目标入口建立连线，条件节点有两个独立出口；也可依次点击端点。点击连线编辑条件，悬停或键盘聚焦连线的「+」可插入步骤并接回后续节点。
- 右侧编辑器用于定义业务含义、必要信息、受理词、人工边界和待接入能力。未保存的表单编辑在切换节点时保留，并阻止提前生成助手。
- 名称、节点和关系需要明确保存；节点移动、布局调整会保存到当前项目。尚未保存的表单编辑只保留在当前页面会话中，刷新前应保存。
- 支持「横向 / 纵向」「从左到右 / 从上到下」「紧凑 / 宽松」「自动整理」等本地布局指令。画布先显示只读预览，用户应用后才写入；修改指令会取消旧预览。
- 名称与头像设置可折叠，提供专注画布模式；退出按钮或 Esc 返回。排版预览有短时位置过渡，尊重减少动态效果设置。
- 保存校验包含单入口、交付出口、连通性、无环、唯一端点、两条不同条件分支及字段长度。当前每份草案最多 20 个节点、32 条关系。
- 长关系标签按行显示，自动排列为标签预留连线空间。自由拖拽后仍应自行核对连线，必要时使用自动整理；不承诺任意手工布局都能避免穿线。

## 从流程生成助手

「核对业务定义」按节点类型整理定义清单，保留所有节点和分支。人工确认后创建新的助手配置草案：

- 入口关键词、必要字段、人工关键词进入本地规则配置，完整业务说明进入 Prompt 草稿。
- 原流程、定义和关系以独立来源快照保存在 `config.flowDesign`。后续配置修改不反向同步画布，后续画布修改也不覆盖既有草案或历史版本。
- 必要字段取全流程字段的合并集合；这不是分支级动态字段执行。
- 所需能力保留为待接入需求，不会自动授予工具权限。
- 不自动写入或修改共享 Ontology；本体库与流程草稿的用途不同。
- 业务定义超出 Prompt 上限会明确阻止生成，不截断规则。
- 所有新助手都有可编辑头像：36 种图案（24 种职责图案、12 种个性伙伴）和六组配色，可在图库中即时预览；原有稳定默认值不变。头像进入配置、验收版本、助手卡片、工作区与项目协作身份。
- 验收通过并经人工确认后才加入本项目的本地团队，不跨项目分派。

**能力边界：这是一套可编辑的业务定义与助手研发原型，不是已接通模型的生产工作流引擎。** 快速排版入口解析明确的布局指令；新增「画布助手」支持规定格式的节点内容、步骤增删、连线和布局指令，先展示差异，确认后应用。任意语义理解、循环流程、任意分支执行和真实业务系统调用均未实现。本地演练继续使用关键词分流、字段检查和草稿整理。

## 前续工作区需求一并落地

- 常用语：输入匹配关键词后出现候选；点击或方向键选中后回车只替换关键词，不覆盖两侧文本、不自动发送。兼容中文输入法、Esc 收起、光标中间插入、内部备注和只读限制。
- 常用语库：保留手动查找、填入、追加与冲突确认；可新增本地通用话术及触发词。新增话术不包含真实客户信息。
- 修复候选展开后输入区被裁切的问题；消息区自适应剩余高度，较长辅助内容可独立滚动。
- 侧栏：日常处理包含客服收件箱、项目助手、项目协作群；管理与研发包含业务助手和 Orbit。历史对话仅在相关页面展开，不再混淆 Orbit 与助手目录的选中状态。

## 业务实例图谱与 Ontology 的区别

业务实例图谱重新围绕「发生范围 / 来源案例 / 核验线索」组织，以问题为中心查看具体记录与关系；Orbit 定义可复用的业务对象、规则和动作。

- 关联检索、来源查看、关系列表和跟进草稿依据本地样本，不虚构真实文档正文或根因结论。
- 「不适用」版本不当作同版本案例的连接键，未知结果不等于已解决。
- 问题分类审核不会修改 Orbit；两者尚未建立自动映射。
