# 全局界面升级 · 2026-11-11

## 本轮范围

沿用连山的米白、苔绿和原有中文字体，升级公共视觉与交互，不新增业务菜单，不调整信息架构，不改变业务处理逻辑。客服工作台仍在第一位，Orbit、业务本体和客户体验继续各司其职。

| 界面 | 调整 |
| --- | --- |
| 全局按钮 | 主操作采用克制的表面明暗、内高光与阴影；次操作用纸白边框；辅助操作不额外加底色。悬停、按下、禁用和键盘焦点分开处理 |
| 侧栏与顶部 | 深苔绿外壳、完整选中面、可辨识的项目切换与功能搜索；不增加侧边色条或循环闪光 |
| Orbit | 研发步骤改成分段导航；整理画布工具栏、属性表单和侧栏层次；节点只调整描边与阴影，拖拽坐标、连线、缩放和修改预览状态不变 |
| 工作台与群聊 | 会话选中边界更明确，输入区聚焦反馈统一；群聊高度、草稿、光标、@ 提及和消息滚动仍由原模块管理 |
| 表单、列表与弹窗 | 统一输入边界、焦点、表格表头、行悬停、对话框表面与页脚操作；保留错误、只读、未接入说明和人工确认 |
| 窄屏与辅助操作 | 导航增加遮罩、收起按钮、焦点约束和 Escape 返回；触控工具按钮增大；减少动态效果与高对比模式单独处理 |

## 实际交互改进

- 同一项目、页面与页签的更新保留主区滚动位置；同一项目侧栏滚动不因刷新丢失。切换页签或项目不套用旧内容的位置。
- 按钮因页面重绘被替换时，只恢复唯一且仍可见、可用的对应控件；不猜测重复目标，不覆盖群聊模块已恢复的输入焦点。
- 新页面使用一次短淡入，不对同页后台刷新反复播放。画布位置与连接点不应用按钮变换。
- 功能搜索可用上下方向键浏览可见结果。Home／End 在结果中跳到首尾；输入框内保留原来的编辑行为。只移动焦点，不自动点击或执行任务。
- 提示允许主动关闭；普通提示保留 6 秒，错误提示 10 秒。鼠标悬停或键盘阅读时暂停消失，离开后继续计时；不会抢走正在输入的焦点。
- 顶部提供键盘可达的“跳到工作区”，不改变当前页面地址或创建新任务。

## 实现边界

新增 `app/interface.css` 与 `app/interface.js` 作为公共层，放在业务样式和模块之后、主应用之前加载。业务模块不依赖这个层才能执行已有功能；公共交互模块没有网络请求、浏览器存储写入、业务状态迁移或全局拖拽监听。

`app/app.js` 仅接入重绘前后、提示和导航开关；`app/icon-help.js` 更新业务本体、Orbit 和客户体验的操作说明。所有 `site/`、`docs/` 文件由构建产生，不手工修改。

本轮不推送代码、不部署到公网、不改变模型连接或客户数据范围。模型业务执行、真实渠道和外部业务系统仍是原来的未接入状态。
